- GIS_POINT_DETAIL_ZOOM=15 — начиная с масштаба 15 точки становятся интерактивными: их можно нажимать и открывать карточку. Ниже 15 они только отображаются.
  - GIS_POINT_ICON_SIZE=32 — фиксированный размер PNG-значков и маркеров с остриём на малом масштабе, в пикселях.
  - GIS_POINT_CIRCLE_SIZE=22 — фиксированный диаметр круглых маркеров на малом масштабе, в пикселях.
  - GIS_POINT_FIXED_SIZE_MAX_ZOOM=15 — порог режима фиксированных размеров. Сейчас фиксированный размер применяется при zoom < 15; начиная с 15 учитывается индивидуальный iconScale.
  - GIS_MAX_POINT_COUNT=300 — максимум 300 точек в одном ответе при zoom <= 15. Линии в лимит не входят. Значение 0 полностью отключает ограничение.

  Таким образом, при текущих настройках:

  - zoom 14: максимум 300 точек, фиксированные размеры, точки не нажимаются;
  - zoom 15: максимум 300 точек, точки нажимаются, начинает учитываться iconScale;
  - zoom 16 и выше: лимита 300 нет, точки нажимаются, учитывается iconScale.

  Есть небольшая разница на границе: лимит действует при zoom <= 15, а фиксированный размер — при zoom < 15.


• GIS_POINT_DETAIL_ZOOM=15 — минимальный масштаб, с которого точки становятся активными.

  - zoom 14 и ниже: точки видны, но нажать и открыть карточку нельзя;
  - zoom 15 и выше: точки доступны для нажатия, выбора объекта и открытия карточки.

  Параметр не управляет размером или количеством точек — только их интерактивностью.
