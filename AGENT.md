## Цель
Создать приложение для разъездных специалистов Интернет оператора
В основе web приложение ТехПортал https://tp.point.online
## Основные задачи
### Первый этап
Работа с заявками на подключение и ремонты, подключение абонентам услуг.
### Второй этап
Работа с оборудованием
## Структура данных
Данные о заявках хранятся в системе ТехПортал, доступна через API
Данные о услугах в системе расчетов UTM5, доступ через REST API
## Структура приложения
Три слоя
frontend
интерфейс пользователя, взаимодействие с backend. Для frontend разные адаптеры по виду взаимодействия с пользователем.
Первый этап - PWA приложение
Второй - telegram bot
Третий - прочие месснджеры
Backend
разбит на два слоя
midllware для взаимодействия с  frontend
backend - адаптеры для взаимодействия с внешними системами
В зависимости от запроса frontend midleware собирает данные через backend и возвращает frontend
## Авторизация пользователя
Авторизация через учетную запись на сайте https://tp.point.online
При удачной авторизации на frontend возвращается access token или coockies которыми в дальнейшем авторизуются все запросы от frontend
### Соглашения
Для backend и middlware используем python
Для frontend - Vite + TaillWind CCS
для тестирования окружение создаем в ./tmmp
