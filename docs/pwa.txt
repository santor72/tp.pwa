## Структура PWA приложения

макет для приложения
#### страница входа
с логином и паролем и кнопкой войти
показывается если текущий сохраненный токен доступа не работает.
#### Основная страница
При успешной авторизации токен доступа сохраняется в localstorage с JWT
Основная страница на три слоя
Внизу меню
- Заявки сегодня
- Заявки Завтра
- Услуги
- Домофон
#### Слой Домофон
Поле ввода service_login подпись логин
кнопка подключить
кнопка Новый
##### По кнопке подключить
отправляется запрос на backend с текстом из поля ввода service_login
пользователю показывается ответ backend и кнопка возврата к основному слою
##### По кнопке  Новый
отправляется запрос на backend domofon_address
результат - List[Dict{int:string}]
int -locid
str - loctext
loctext показываются пользователю плитками
при нажатии на плитку запоминается locid соответствующий плитке
переход на следующий экран
поле ввода Квартира field_flat - целое число
поле Ввода подъезд - field_podezd - целое число
поле ввода ФИО - client_name - строка
поле ввода Номер телефона - phone - необязательная строка
кнопка Создать
Все три поля ввода обязательны
По кнопке Создать отправляется запрос на backend с locid, field_flat, field_podezd, client_name и phone, если номер заполнен
пользователю показывается ответ backend и кнопка возврата к основному слою
#### На слоях заявок
заявки из baсkend плитками с возможностью их посмотреть и отметить как исполненные по кнопке или свайпу плитки
заявки приходят в json поля - short: string, description: string, date: datatime, phones: массив строк, "additional" - дополнительные данные, не отражаются на плитке, "comments" -  List of string не отражаются на плитке
каждый элемент из Phones отображается как ссылка с возможностью набрать номер
При нажатии на плитку  открывается экран заявки на нем
short
description
Phones  Phones отображается как ссылка с возможностью набрать номер
 additional
 comments - сообщений
 В этом экране пользователь может
 Отметить заявку как завершенную
 Добавить комментарий
 Действия пользователя отправляются на backend
#### Слой Услуги
combobox services_select со списком услуг для подключения
Поле ввода service_login подпись логин
кнопка подключить
##### По кнопке подключить
отправляется запрос на backend с текстом из поля ввода service_login
и выбором в services_select.
переход на следующий экран.
Backend возвращает json
"description" - description строка описания
"login" - строка логин пользователя
list - список уcлуг для подключения service_list.
description отображается заголовком
Список отображается в виде radio group + кнопка подключить
кнопка Подключить
пользователь выбирает услугу
Нажимает подключить - запрос отправляется на backend
переход на следующий экран
с выбранной услугой и login
backend возвращает в ответ текст который отображается пользователю
и кнопка возврата к основному слою
