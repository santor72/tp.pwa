# План: загрузка неизвестных значков GIS

Текущий этап намеренно не делает сетевых запросов за PNG-значками. В PWA будет
локальный каталог `iconId → файл`; неизвестный `iconId` отображается стандартной
точкой с `iconColor`.

Будущий этап:

1. По неизвестному `iconId` запросить защищённый backend-прокси GIS.
2. Сохранить полученный PNG в кэше PWA с ключом `iconId` и версией каталога.
3. При следующем показе использовать кэш; при ошибке оставить стандартную точку.
4. Ограничить размер и срок хранения кэша, предусмотреть очистку при обновлении
   каталога GIS.

Перед заполнением локального каталога нужно получить из работающей GIS экспорт
таблицы assets: UUID, файл и контрольную сумму. UUID создаются в базе GIS, а не
являются постоянными идентификаторами исходного кода.
