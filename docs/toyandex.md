  1. Подключить Яндекс JavaScript API 2.1. Добавить настройку ключа и разрешить загрузку ресурсов Яндекса. Проверить ограничения ключа для домена PWA.
  2. Заменить Leaflet в общем компоненте карты. Изменение охватит основной экран GIS и выбор объекта в заявке.
  3. Добавить две подложки: «Схема» и «Гибрид». Выбранный режим сохранять в localStorage под ключом tp-pwa.gis.basemap:
      - восстанавливать при открытии карты и после перезапуска PWA;
      - использовать один выбор для обоих экранов;
      - по умолчанию показывать схему;
      - при недоступном хранилище или некорректном значении карта должна продолжать работать.

  4. Сохранить отображение объектов: PNG-значки, прозрачность, размеры, перекрашивание, резервные круглые маркеры, стили линий и полигонов. Использовать существующие данные и адреса загрузки изображений.
  5. Перенести управление картой: выбор объекта и открытие карточки, геолокацию, масштабирование, полный экран, сохранение положения и загрузку объектов по видимой области. Переключение подложки должно сохранять положение карты и выбранный объект.
  6. Обработать ошибки загрузки API. Показывать понятное сообщение и возможность повторить загрузку.
  7. Проверить результат: обе подложки, восстановление выбора из localStorage, PNG-точки и карточки на обоих экранах, точность координат, работу на телефоне и производительность на реальных данных.
